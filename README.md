## How to use

1. Click the **Open in Colab** badge for the module you want.
2. In Colab, choose **File → Save a copy in Drive** so your changes are saved.
3. In Modules 2–4, run the **Setup – run this first** cell before anything else.
4. Work through Part A, then try the exercises in Part B.
